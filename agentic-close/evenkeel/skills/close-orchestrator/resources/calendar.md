# Close calendar (Kitewell, fictional)

Workdays are counted from period end: WD+1 is the first business day of the next month.

| WD | Tasks |
|---|---|
| +1 | Import source files; code card transactions |
| +2 | Bank reconciliations (3 accounts); journal entry review |
| +3 | Accruals; prepaids; fixed assets; AP and AR tie-outs; intercompany; FX revaluation |
| +4 | Flux analysis (after every adjustment) |
| +5 | Close package; CFO sign-off; lock the period |

A task is **satisfied** when it is prepared (ready for review or complete) and none of its
proposals await a decision. Downstream agents never run on numbers that are about to change.
